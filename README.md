# 🏡 Ingrid Bossa — Corretora de Imóveis (Toledo - PR)

Site imobiliário moderno de alta conversão para a corretora **Ingrid Bossa** (CRECI F-58168), focado no mercado de Toledo/PR e região Oeste do Paraná.

## 🚀 Tecnologias

- **Next.js 14** (App Router, Server & Client Components)
- **Tailwind CSS 3** (Design System com paleta Champagne, Rose Bronze & Deep Slate de alto padrão)
- **Lucide Icons** (Iconografia moderna)
- **Swiper.js** (Carrossel e galerias de imagens interativas)
- **Supabase** (PostgreSQL Database & Auth)
- **Cloudinary** (Upload e otimização de imagens)
- **Prisma ORM** (Modelagem de dados)
- **TypeScript** (Tipagem estrita e autocomplete)

## 📌 Funcionalidades

- **Hero Section Exclusivo** com atmosfera acolhedora e paisagem de Toledo
- **Buscador Principal** com categorias e bairros de Toledo
- **Cards de Imóveis Modernos** com zoom suave, especificações claras e botão de WhatsApp direto
- **Página Interna do Imóvel** com galeria interativa, lista de comodidades e CTA contextual
- **Painel Administrativo da Corretora (`/admin`)** com cadastro, edição, upload e status dos imóveis
- **Integração com WhatsApp Oficial**: (45) 99810-0534
- **Integração com Instagram Oficial**: [@ingridbossa_corretora](https://www.instagram.com/ingridbossa_corretora/)

## 🛠️ Como Executar Localmente

```bash
# 1. Instalar dependências
npm install

# 2. Executar servidor de desenvolvimento
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.
